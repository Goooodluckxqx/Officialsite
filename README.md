# NazzleNest Official Website — English Version

NazzleNest smart home comfort solutions — English website built with Next.js 14 + Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
npm run build
```

## Project Structure

```
src/
  app/              # Next.js App Router pages
    page.tsx        # Home page
    layout.tsx      # Root layout
    about/          # About Us
    blog/           # Blog pages
    guides/         # Buying Guide
  components/       # Reusable components
    Navbar.tsx
    Hero.tsx
    Products.tsx
    Reviews.tsx
    FAQ.tsx
    Footer.tsx
```

## Deployment

Connected to Vercel for automatic deployment on push to `main`.
